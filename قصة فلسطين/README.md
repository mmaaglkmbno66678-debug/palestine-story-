# فلسطين | حكاية لا تنتهي

تجربة وثائقية تفاعلية بالعربية، من خمسة عشر مشهدًا كامل الشاشة، تجمع بين الصورة والتاريخ والذاكرة والثقافة. بُنيت بـ HTML وCSS وJavaScript فقط، دون مكتبات خارجية أو طلبات شبكة أثناء التشغيل.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا ثابتًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`. تعمل التجربة دون اتصال بالإنترنت بعد تنزيل الملفات.

## التنقل

- زرّا السهم في أسفل الشاشة، أو النقاط الخمس عشرة على اليمين (اتجاه RTL).
- لوحة المفاتيح: الأسهم، `PageUp` / `PageDown`، مسافة، `Home`، `End`.
- عجلة الفأرة أو السحب بالإصبع. في الشاشات القصيرة يُمرَّر داخل المشهد أولًا، ثم ينتقل السحب إلى المشهد التالي عند الوصول إلى الحافة.
- كل مشهد له رابط مباشر عبر `#s1` … `#s15`.
- شريط التقدم وعدّاد «٠١/١٥» يعرضان الموضع الحالي.

## الموسيقى

- الأغنية المطلوبة هي «هل أراك سالمًا منعّمًا».
- تبدأ **فقط** عند ضغط الزائر على زر «ابدأ الحكاية»؛ لا يوجد تشغيل تلقائي عند فتح الصفحة.
- **ملف صوتي واحد فقط**: `assets/audio/palestine-song.mp3` — الملف الذي أرفقه المستخدم (ElevenLabs / صوت Sultan). استبدله بأي MP3 تملك حق استخدامه بالاسم نفسه. راجع `assets/audio/README.md`.
- تعمل الأغنية في حلقة مستمرة طوال المشاهد، ولا تُعاد عند الانتقال بينها. يُحفظ موضع التشغيل ويُستأنف منه.
- مستوى البداية 30%، والزر الصغير في الشريط العلوي يكتم الصوت ويعيده فقط.
- لا توجد واجهة لرفع أو اختيار ملف من جهاز الزائر، ولا تُضمَّن تسجيلات محمية في المشروع.
- إن لم يكن الملف متاحًا، يعمل الموقع بصمت من دون رسائل خطأ أو نوافذ مزعجة.

## البنية

| الملف | الوظيفة |
| --- | --- |
| `index.html` | المشاهد الخمسة عشر، الشريط العلوي، نافذتا المصادر والحقوق |

| `assets/audio/` | ملف الموسيقى وتعليماته |
| `image-sources.md` | جدول كامل بكل صورة ومؤلفها وترخيصها ورابطها |
| `sources.md` | المصادر التاريخية والوثائق والمواقع الرسمية المستخدمة |

## المصادر والتحقق

رُوعي في النصوص ألا تُخترع أرقام أو مصادر. الخرائط التاريخية (1947 و1967) وثائق أرشيفية، وليست خرائط للوضع الحالي؛ والخرائط التوضيحية في المشهدين 2 و9 من تصميم المشروع ولا تمثل حدودًا سياسية. الصور الأرشيفية معلَّمة بتواريخها، ولا تُعرض صور مولّدة بالذكاء الاصطناعي على أنها وثائق. لا يعرض مشهد غزة أرقام ضحايا أو نازحين ثابتة لأنها تتغير؛ يُحال القارئ إلى OCHA والأونروا.

آخر مراجعة للنصوص والمصادر: **نوفمبر 2026**.

## إمكانية الوصول

- تخطيط RTL كامل، وتسميات `aria` لكل عنصر تفاعلي، ومشهد مُعلَن لقارئ الشاشة عند كل انتقال.
- دعم `prefers-reduced-motion`: تُوقف حركة الصور والتأثيرات.
- أثر الخطوط الحمراء يعمل بالفأرة فقط على الشاشات الواسعة، ويُعطَّل على اللمس والشاشات الصغيرة و Reduced Motion.
- نسخة طباعة تقرأ فيها المشاهد كصفحة عادية.

التوقيع: **من صنع ملك عبدالسلام زايدة**.
